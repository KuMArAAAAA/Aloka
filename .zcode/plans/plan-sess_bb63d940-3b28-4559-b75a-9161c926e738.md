# Aloka — Klaim & Tarik Tunai (POS Indomaret Simulasi) + UI Referensi SNPMB

## Context
Alur: login siswa NISN+tgl lahir → embedded wallet otomatis (invisible) → Klaim → escrow release ke wallet siswa on-chain → QR + kode PIP-XXXXXX + PIN → "POS Indomaret" (halaman `/kasir` simulasi) → kode + PIN → tunai 100%. Proposal Phase 1 terpenuhi literal (Wallet Module, Verify Wallet & Beneficiary Match, transfer ke wallet penerima); modul kasir = lapisan tambahan setelah "Funds Received by Student". Sekalian membenahi bug: `distributeAid` saat ini kirim mIDR ke alamat GOV, bukan siswa.

## Tool & Bahan
- Terpasang: Node ≥18, Foundry, Supabase PostgreSQL, ethers v6, Next.js 14, Tailwind.
- Install: `qrcode.react` (wajib, frontend). Opsional: `html5-qrcode` (scan webcam di kasir).
- Bahan: mnemonic server via `cast wallet new-mnemonic` → `ALOKA_WALLET_MNEMONIC`; POL Amoy (faucet); update address kontrak pasca-redeploy.

## 1. Design System — Referensi Portal SNPMB
Prinsip: "portal resmi pemerintah", clean & formal, bukan aplikasi crypto. Tanpa UI library baru (Tailwind saja).
- **Navbar**: putih sticky, logo pemerintah + brand "Aloka — Portal Bantuan Pendidikan", menu: Beranda · Transparansi · Panduan, tombol "Masuk". Border bawah tipis.
- **Hero landing** (pola SNPMB): heading besar + 1 paragraf + 2 CTA: "Cek Status Bantuan" → `/siswa`, "Sudah Punya Akun? Masuk" → `/login`; ilustrasi pendidikan (Storyset/undraw), strip pengumuman di bawahnya.
- **Palet**: putih dominan; biru institusional primer (button/link/stepper); slate teks; hijau sukses & merah error untuk status. `/kasir`: aksen merah-kuning ala Indomaret + label "Simulasi POS Indomaret (Demo)".
- **Komponen**: kartu rounded shadow tipis, badge status (reuse `StatusBadge`), stepper klaim 4 langkah, form minimal (label jelas + helper text + tombol besar), footer resmi (copyright + kredit ilustrasi + disclaimer demo hackathon).
- **Font**: Plus Jakarta Sans atau Inter.
- Halaman direstyle: `/` (landing), `/login`, `/siswa`, `/kasir` (baru), `/transparansi`, Navbar/Footer.

## 3. Backend (0 dependensi baru)
- `backend/prisma/schema.prisma`: `Student` + `walletIndex Int?`; model `Claim` {id, applicationId unique, code unique, pinHash, amountSnapshot BigInt, status ACTIVE/REDEEMED/EXPIRED, expiresAt, redeemedAt, createdAt}; `prisma db push`.
- `services/wallet.service.js` (baru): `provisionEmbeddedWallet` — HD derivation `m/44'/60'/0'/0/{index}` dari `ALOKA_WALLET_MNEMONIC`, lazy saat login siswa; reuse pola `prisma/seed.js:12–34`.
- `services/claim.service.js` (baru): `createClaim` (app VERIFIED milik siswa → `distributeAidOnChain` existing `blockchain.service.js:286–352` → buat Claim: kode `PIP-`+6 char, PIN 6-digit, expiry 72 jam, AuditLog → return `{code, pin, qrPayload, amount, expiresAt}`); `redeemClaim({code,pin})`; `reissueClaim`.
- `routes/claim.routes.js` + `schemas/claim.schema.js`: `POST /claims` (STUDENT), `POST /claims/redeem` (public, rate-limit ketat), `GET /claims/me`, `POST /claims/:id/reissue`; mount di `routes/index.js`.
- `services/blockchain.service.js`: `submitApplicationOnChain` kirim `beneficiary = student.walletAddress` (provisioned wajib); verifikasi wallet↔NISN dipertahankan.
- `.env.example`: `ALOKA_WALLET_MNEMONIC`, `CLAIM_TTL_HOURS=72`. Hapus 4 file junk 0-byte di `backend/`.
